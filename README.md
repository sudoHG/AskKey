# AskKey

A local credential manager for humans and AI agents on macOS.

Credentials are encrypted on your Mac. Agents such as Codex, Cursor and Grok CLI can request them only through a restricted helper and a local broker inside the app. Each credential is set to **Allow**, **Ask** (default) or **Hidden**; when approval is needed, AskKey shows a dedicated prompt and delivers the approved value to the target process without returning stored plaintext to the agent.

> **Status:** under active restructuring before the first public release. Not ready for general use.
